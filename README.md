## 📁 Estrutura

```
connect-digital/
├── index.html          ← Home
├── sobre.html          ← Sobre Nós
├── servicos.html       ← Serviços (8 serviços)
├── contato.html        ← Contato
├── vercel.json         ← Configuração Vercel
└── assets/
    ├── css/
    │   ├── main.css    ← Design system
    │   ├── home.css
    │   ├── sobre.css
    │   ├── servicos.css

```
